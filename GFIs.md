# Good First Issues

## Add a smaller box suggestion
For flagged rows, suggest the largest box dimension reduction that would bring dimensional weight at or below actual weight, and show it in the results table and export.

## Support per carrier divisor presets
Add named presets for common carrier and service combinations so users can pick a carrier instead of typing a divisor number.

## Add a rate delta estimate column
Let users enter a per pound rate and show an estimated per shipment overcharge for each flagged SKU.
